2.3. Module [H3]: Bảng Danh Sách Nhân Vật & Quy Tắc Hoạt Ảnh Xuất Hiện 7,2 Giây (*²)
Khi người chơi bấm vào nút Icon 'Cây viết chỉnh sửa' (*¹) ở khung [H2], hệ thống mở giao diện Chọn & Xem Chi Tiết Nhân Vật [H3] với bố cục 3 phần: Bảng Danh sách 12 Hồn Sư bên trái, Mô hình Nhân vật 3D đứng trên Bệ Đài ở chính giữa, và Bảng Chi tiết Kỹ năng / Thuộc tính / Nhánh / Trợ phẩm ở bên phải:
  

Hình 4: Giao diện Bảng Danh Sách & Chi Tiết Nhân Vật [H3] mở ra khi bấm Icon Cây Viết (*¹) — Bỏ hoàn toàn các bộ lọc thừa ở bảng trái, nhân vật 3D đứng giữa chạy hiệu ứng xuất hiện tự động lặp lại sau mỗi 7,2 giây (*²), và đồng bộ tức thì thông tin giữa 2 bảng.
QUY TẮC BẮT BUỘC KHI TRIỂN KHAI MODULE [H3] & BỘ ĐẾM HOẠT ẢNH 7,2 GIÂY (*²)
1. Loại bỏ toàn bộ các thanh lọc thừa: Tuyệt đối KHÔNG hiển thị các nút lọc 'Chủ động / Bị động' hay các tab 'Tất cả, Đồng đội, Sinh tồn, Tấn công, Thông tin' như Free Fire. Hiển thị trực tiếp lưới thẻ 2 cột của 12 Hồn Sư (Lâm Dật, Hàn Trạch, Ly Sa, Kỳ Vân, Tịch Dao, Đỗ Kình, Vân Chước, Sở Băng Nghi, Mặc Tinh, Thiên Lạc, Ninh Từ, Tạ Uyên).
2. Cơ chế đồng bộ tức thì giữa 2 bảng: Khi người chơi bấm chọn một thẻ nhân vật ở bảng danh sách, toàn bộ thông tin của nhân vật đó (Tên, Võ hồn, Mô tả kỹ năng Q/W/E/R, 8 Thuộc tính, 3 Nhánh tiến hóa, 3 Trợ phẩm) sẽ tự động cập nhật ngay lập tức qua bảng chi tiết đối diện và lưu vào khung [H2].
3. Quy tắc Hoạt ảnh Xuất hiện 7,2 giây (*²): Ở chính giữa 2 bảng vẫn là nhân vật 3D đứng trên Bệ Đài. Khi bấm chọn nhân vật sẽ chạy Hiệu ứng Xuất hiện (Entrance Animation). Sau mỗi 7,2 giây (7200ms) nếu người chơi không thay đổi nhân vật, hiệu ứng xuất hiện sẽ tự động chạy lại một lần!

let entranceReplayTimer = null;
const ENTRANCE_REPLAY_INTERVAL_MS = 7200; // Đúng 7.2 giây theo quy tắc (*²)


function clearEntranceReplayTimer() {
  if (entranceReplayTimer !== null) {
    clearTimeout(entranceReplayTimer);
    entranceReplayTimer = null;
  }
}


function scheduleEntranceReplay(heroId) {
  clearEntranceReplayTimer();
  entranceReplayTimer = setTimeout(() => {
    if (gameState.currentView === 'LOBBY_HON_THANH' && gameState.selectedHeroId === heroId) {
      playHeroEntranceAnimation3D(heroId, { onComplete: () => scheduleEntranceReplay(heroId) });
    }
  }, ENTRANCE_REPLAY_INTERVAL_MS);
}

  const heroData = HERO_DATABASE_V25[heroId]; // H01..H12 từ GDD V2.5
  if (!heroData) return;
  gameState.selectedHeroId = heroId;
  renderHeroQuickPanelH2(heroData);
  renderHeroDetailPanelH3(heroData);
  updateTopLeftProfileAvatarH1(heroData.avatarUrl);
  playHeroEntranceAnimation3D(heroId, { onComplete: () => scheduleEntranceReplay(heroId) });
}
