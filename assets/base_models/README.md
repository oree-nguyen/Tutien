# Model gốc tạo thủ công

Chép GLB xuất từ web Hunyuan vào đây bằng đúng tên trong [Asset Sheet](../../Prompt_Asset/hunyuan_asset_prompts.md).

Đây là vùng nhận file trước kiểm định, không phải thư mục model đang được game tự động sử dụng. Xem [hướng dẫn offline](../../Prompt_Asset/README.md).

H01-C0 và H01-W0 đang có bản dẫn xuất mobile Meshopt/WebP, có ghi provenance; không nhầm với raw export. Công cụ intake kiểm cấu trúc được, nhưng Blender cần bản chưa nén/đã giải mã Meshopt để chỉnh sửa. Raw thân ở `.local/manual-assets/`, raw trượng ở `h01_moc_tinh_truong_raw.glb` (không commit). Xem [quy trình H01](../../docs/H01-STAFF-ENTRANCE.md).
